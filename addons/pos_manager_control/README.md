# POS Manager Control

Планируемый модуль подтверждения критичных операций менеджером:

- возврат товара;
- удаление позиции и отмена заказа;
- изменение цены и ручная скидка;
- открытие денежного ящика;
- расхождение при закрытии смены;
- доступ к служебным функциям.

Модуль пока не реализован и намеренно имеет `installable: False`.
