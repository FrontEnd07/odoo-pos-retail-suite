# POS 1C Exchange

Планируемый первый этап интеграции с 1С:Розница 8.3:

- товары и штрихкоды: 1С → Odoo;
- розничные цены: 1С → Odoo;
- продажи и возвраты: Odoo → 1С;
- закрытие смен и оплаты: Odoo → 1С;
- идемпотентность и журнал ошибок обмена.

Остатки на первом этапе не синхронизируются.
