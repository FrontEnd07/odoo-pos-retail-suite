# POS Offline Monitor

Планируемая панель наблюдения за кассами:

- online/offline-состояние моноблока;
- время последнего heartbeat;
- количество локально сохранённых чеков;
- состояние синхронизации и последняя ошибка;
- версия POS-интерфейса и локального агента;
- предупреждения о длительном отсутствии связи.

Модуль пока не реализован и намеренно имеет `installable: False`.
