# Архитектура

## Принципы

- Ядро и стандартные модули Odoo не изменяются.
- Каждый функциональный блок поставляется отдельным модулем.
- `pos_retail_suite` устанавливает только стабильные обязательные компоненты.
- Временные исправления не смешиваются с бизнес-функциями.
- Секреты, дампы баз, логи и данные магазинов не хранятся в Git.

## Планируемые компоненты

- `pos_manager_control` — подтверждение критичных операций менеджером.
- `pos_offline_monitor` — централизованный контроль offline-очередей.
- `pos_1c_exchange` — товары и цены из 1С, продажи и смены в 1С.

Эти каталоги будут добавляться только вместе с работающим кодом и тестами.
